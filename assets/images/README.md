# Image Placement Guide

Place your images in this folder (`swarajElec/assets/images/`) with the following filenames:

## Required Images

### Hero Image
- `hero.png` — Main hero section image (recommended: 500x500px or larger, transparent background preferred)

### Weighing Scale Products
- `WS-001.png` — Digital Table Top Scale
- `WS-002.png` — Industrial Platform Scale
- `WS-003.png` — Electronic Shop Scale
- `WS-004.png` — Heavy Duty Weighbridge
- `WS-005.png` — Precision Lab Scale
- `WS-006.png` — Hanging / Crane Scale

### RO & Water Products
- `RO-001.png` — Home RO Water Purifier
- `RO-002.png` — Commercial RO System
- `RO-003.png` — Industrial RO Plant
- `RO-004.png` — Under-Sink RO Unit
- `RO-005.png` — UV Water Purifier
- `RO-006.png` — Water Softener System

### Services (optional - can skip if you don't have these)
- `SV-001.png` — Installation Service
- `SV-002.png` — Annual Maintenance (AMC)
- `SV-003.png` — Repair & Maintenance
- `SV-004.png` — Calibration Service

### About Section (optional)
- `about.png` — Shop / Showroom photo (recommended: 600x400px)

## Image Tips
- Use PNG or WebP for transparent backgrounds
- Recommended product image size: 300x300px to 500x500px
- Keep file sizes under 200KB each for fast loading
- Use consistent aspect ratios across all product images
